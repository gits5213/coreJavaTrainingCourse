# Part 15 — Wrapper Classes

Collections hold **objects**. The primitive types `int`, `double`, and `boolean` are not objects.

A **wrapper class** is an object version of a primitive:

```text
int      →  Integer
double   →  Double
boolean  →  Boolean
```

**Autoboxing** converts primitive → wrapper for you.  
**Unboxing** converts wrapper → primitive for you.

This part is short. It unlocks `List<Integer>` and `Map<String, Integer>` — daily SDET tools for status codes and counts.
