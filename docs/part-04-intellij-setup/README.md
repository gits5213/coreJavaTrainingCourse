# Part 4 — IntelliJ Setup

This is the first part where your hands do what your brain has been reading about.

We will install **JDK 25 LTS**, install **IntelliJ IDEA**, create a project named **java-learning**, write a first program, and learn comments.

We start with **IntelliJ's own Java project (IntelliJ build system)**. Maven is excellent and we will use it later. On day one, extra build tools are fog.

---

## What This Part Is For

By the end of Part 4 you should have:

- `java -version` and `javac -version` both showing **25**
- an IntelliJ project named **java-learning**
- a program you typed that prints output
- a habit of writing comments that help, not comments that narrate the obvious

That is the practical half of **Level 1**.

## How to Study Part 4

- Do the clicks on your machine. Reading about an IDE is not using an IDE.
- If something fails, write down the **exact** error text. That is already SDET behavior.
- After Hello World runs, break it on purpose. Then fix it. Confidence comes from recovery.

---

## SDET Thread

Your future test framework will be an IntelliJ project too. If the IDE is a mystery, every later tool (JUnit, Selenium) will feel twice as hard. Part 4 is not a side quest. It is the shop floor.
