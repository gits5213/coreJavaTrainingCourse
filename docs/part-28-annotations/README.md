# Part 28 — Annotations

An **annotation** is metadata: a note on a class or method that tools and the compiler can read.

You already saw `@Override`. Test libraries add `@Test`. You will not write a test framework today. You will understand that `@Test` is not Java "running tests by magic in the language." It is a **marker** a library looks for.
