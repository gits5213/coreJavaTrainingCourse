# Part 57 — Reporting

A run that nobody can read is theater.

```text
Test Execution
      ↓
Results
      ↓
Evidence
      ↓
Report
```

Evidence: screenshot, exception, browser, environment, timestamps.

Possible tool: **Allure**.
