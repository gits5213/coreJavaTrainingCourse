# Part 36 — GitHub

Git lives on your computer. **GitHub** is where the team puts the shared copy of the repository, reviews changes, and runs CI.

This part is a workflow lesson, not a tour of every GitHub button.

```text
Local Repository
       ↓
GitHub Repository
       ↓
Pull Request
       ↓
Code Review
       ↓
CI
       ↓
Merge
```

## Lesson in This Part

| Lesson | Topic |
| --- | --- |
| [GitHub Workflow](github-workflow.md) | Local → GitHub → PR → review → CI → merge |

## Prerequisite

Chapter 92. You can commit locally. You have (or will create) a GitHub account.

## SDET Connection

Your automation does not count as "done" when it passes on your laptop. It counts when it is reviewed, green on CI, and merged to `main`.
