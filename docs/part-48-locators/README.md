# Part 48 — Locators

A **locator** is how Selenium finds an element.

```java
By.id()
By.name()
By.cssSelector()
By.xpath()
By.linkText()
```

Prefer **stable** selectors. Avoid absolute XPath, generated IDs, fragile CSS chains, and visual position.
