# Part 59 — Code Review

Students must learn to **review Java**, including test Java. A PR that "passes CI" can still be a design failure.

Curriculum questions (memorize them as a checklist):

```text
Does this method have one purpose?
Are names meaningful?
Is duplication justified?
Is exception handling correct?
Are resources closed?
Is shared state safe?
Are tests independent?
Are secrets exposed?
Is inheritance necessary?
Could composition be simpler?
Is code testable?
```
